## The plan (steps by agent)

NET (crates/net only):
1. Jitter buffer: estimate one-way delay per buffer as the minimum over the last 64 arrivals of
   (arrival universe time - snapshot time); sample at now - latency - delay; add `rebase(f)` to convert
   every stored snapshot on a frame switch. Test: 150 ms latency, +-20 ms jitter, 5% loss, 10 m/s circle:
   error < 2 cm and zero frozen frames.
2. Room relay keeps up to 4 records per player and kind since the last tick and forwards all, in order.
   room_alloc test still 0 allocations per tick.
3. Protocol 2 (DO THIS FIRST, commit it alone, report the hash to the lead at once): `PROTOCOL = 2`.
   `CompanionBody` appends face: `expr: u8` and `face: u8` (lid 2 bits, gaze x 2 bits, gaze y 2 bits,
   beat 1 bit). `ShipBody` appends `stick: [f32; 2]` (i8 each, -1..1) and `boost: f32` (u8).
   `PlayerRecord` appends `marks: String`. New `Waypoint { body: BodyId, dir: [f32; 3], name: String }`.
   Append `ClientMsg::Explored { body, cells: Vec<u32> }`, `ClientMsg::Waypoint(Option<Waypoint>)`,
   `ServerMsg::Explored { body, cells: Vec<u32> }`, `ServerMsg::Waypoint { player, waypoint }`.
   `Welcome` appends `explored: Vec<(BodyId, Vec<u64>)>` and `waypoints: Vec<(PlayerId, Waypoint)>`.
   Cell index = row * 512 + column, row 0 at the south pole, column 0 at longitude 0 going east.
4. Room merges explored cells per body into 2048-word bitsets, broadcasts only new cells at most once per
   second per body; one live waypoint per player, cleared on leave; store saves explored in
   `data/explored.bin` (postcard, atomic) beside world.toml.
5. The rustls filet warning at crates/net/src/trust/verify.rs:82 (`verify_server_cert` takes 6 parameters,
   limit 5): the owner wants it gone. The signature is fixed by rustls's `ServerCertVerifier`. Make filet
   clean without disabling the rule and without weakening the verifier: for example implement the trait
   through a small `macro_rules!` that expands the method, with the logic in a 2-parameter function
   (certificate, verifier state). Explain the choice in the report.

normal (>= 0.64) within 0.35 m, move there; smooth the eye height over 0.12 s. Only on the ground, on
foot. Tests in new `src/player/tests/steps.rs` on the `stage.rs` rig: a 0.29 m box climbed, a 10-step
