# Perf audit: render and shaders (read-only, no timing). Game renders at 360 rows (render/tune.rs:8).
1. Cover map staging burns main-thread CPU every frame per map: render/clouds/map.rs:17-25 (SLICE 512, PACE 131072), map.rs:82-86, maps.rs:151-158. ~2.7k texels/frame, each texel_dir + DQuat::from_rotation_y + broad() (4 lattices). Needs only 393,216 texels per 16 s. Fix: PACE ~16384, SLICE ~256; hoist per-snapshot constants (stream keys, DQuat) out of texel loop; share one budget across maps; best: stage on compute pool.
2. Cloud shell rebuild stalls main thread: render/clouds/mesh.rs:55-66, shell.rs:101-124, shell.rs:11 (TOLERANCE 50 m), clouds.rs:123. ~100k+ verts near orbit, rebuild at every 1.5x growth of need. Fix: tolerance scaled with altitude (error <= 0.01*distance to nearest shell point), or build in a task and swap; RenderAssetUsages::RENDER_WORLD.
3. Cover map build 4x heavier, single task: maps.rs:112-117, map.rs:125-129 (393k texels, Globe::of for non-streamed planet; `_` arm of advance computes 2x393k synchronously on time jump). Fix: split per face (6 tasks) / par_chunks; never do the sync arm on main thread.
4. Galaxy light bake: galaxy_light.rs:48-52,155-175, march.rs:149-165: 6 OS threads via thread::scope inside a compute task; back-to-back rebakes during fast flight. Fix: half the cores or compute pool; minimum interval of a few seconds between bakes.

Fix: skip Hidden bodies; build uniform, compare with get() before get_mut (as blades/mod.rs:84, sea/ember.rs).
