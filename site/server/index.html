Guide, multiplayer

Host a server

A server lets your friends join your universe. It keeps the world for everyone: the seed, the clock, what you all found, and where each player left their ship.

It is small. Each player uses about 10 KB/s, and a Raspberry Pi is enough.

Or just play on space.facile.studio, already in the game's server list.

01 Play on your network

No server needed. In the game, pause and choose Open to LAN.

Friends on the same Wi-Fi see your world under Multiplayer, On your network. There is nothing to set up.

If they do not see it, allow UDP ports 24650 and 24651 in your computer's firewall.

02 One command

For Linux on x86_64 or arm64, Raspberry Pi included (with a 64-bit system). There is no macOS or Windows build of the server: use Docker there.

Install it:

curl -fsSL https://abstractions.facile.studio/server.sh | sh

Start it:

abstractions-server

The first start creates a data folder where you run it, with a new world and a random seed. Then it prints something like this:

Abstractions server v0.10.0
World     My universe (seed 482190773615204871)   ./data/world.toml
Listening UDP 24650 on all addresses (0.0.0.0)
Join at   192.168.1.20:24650
Key       7F3A-91C2-0B5E   players see this the first time they join
Internet  forward UDP port 24650 to this machine, or point a domain at it

Stop it with Ctrl-C. It saves the world first.

The script puts the server in ~/.local/bin, or in /usr/local/bin when run as root. It checks the download against its SHA-256 checksum. Read the script.

03 With Docker

The image runs on x86_64 and arm64. The world lives in the abstractions volume.

docker run -d --name abstractions -p 24650:24650/udp -v abstractions:/data --restart unless-stopped ghcr.io/saravenpi/abstractions-server

See the banner and the key:

docker logs abstractions

Or with Docker Compose, in a file named docker-compose.yml:

services:
  abstractions:
    image: ghcr.io/saravenpi/abstractions-server
    ports:
      - "24650:24650/udp"
    volumes:
      - abstractions:/data
    restart: unless-stopped
    environment:
      ABSTRACTIONS_NAME: "My universe"
      ABSTRACTIONS_PASSWORD: "change-me"

volumes:
  abstractions:

Remove the two environment lines you do not need, then start it:

docker compose up -d

04 Keep it running

On a machine with systemd, the script can install the server as a service. It starts with the machine and restarts if it crashes.

curl -fsSL https://abstractions.facile.studio/server.sh | sudo sh -s -- --service

This puts the server in /usr/local/bin, creates a system user named abstractions, and keeps the world in /var/lib/abstractions. The service can write to that folder only.

Check it:

systemctl status abstractions-server

Follow the logs:

journalctl -u abstractions-server -f

Stop it, or start it again:

sudo systemctl stop abstractions-server
sudo systemctl start abstractions-server

To change a setting, open the override file, add the lines below, save, then restart:

sudo systemctl edit abstractions-server
[Service]
Environment="ABSTRACTIONS_NAME=My universe"
Environment="ABSTRACTIONS_PASSWORD=change-me"
sudo systemctl restart abstractions-server

To remove the server and the service, add --uninstall instead. The world folder stays.

05 Let friends in from the internet

First, on your router, forward UDP port 24650 to the machine that runs the server. Router pages call this port forwarding or virtual server. Pick UDP, not TCP.

Then open the firewall on that machine. On Ubuntu, Debian and Raspberry Pi OS:

sudo ufw allow 24650/udp

On Fedora:

sudo firewall-cmd --add-port=24650/udp --permanent && sudo firewall-cmd --reload

Last, give friends your public IP address. Or point a domain at it: add an A record with your public IP.

Using Cloudflare? Set the record to DNS only (grey cloud). Cloudflare's proxy only carries web traffic, so friends cannot reach the server through it.

The game talks over UDP. Some school or office networks block it, and nobody on those networks can reach any server.

06 Settings

Use a flag or an environment variable. You never need any of them.

FlagEnvironment variableDefaultWhat it does
--nameABSTRACTIONS_NAMESet on first startThe name in the server list.
--passwordABSTRACTIONS_PASSWORDNonePlayers type it to join. The server never prints it.
--portABSTRACTIONS_PORT24650The UDP port it listens on.
--max-playersABSTRACTIONS_MAX_PLAYERS16How many players can be in at once.
--dataABSTRACTIONS_DATA./data, /data in DockerThe folder for the world and the key.
--import <file>NoneNoneStarts from a single-player world.

For example:

abstractions-server --name "Kodya friends" --max-players 8

07 Bring your single-player world

Each world is one .toml file. Copy it to the server machine, then:

abstractions-server --import <path to the world file>

The game keeps its world files here:

  • Linux~/.local/share/abstractions/worlds/
  • Windows%APPDATA%\abstractions\worlds\
  • macOS~/Library/Application Support/abstractions/worlds/

08 The server key

The first time you join a server, the game remembers its key, like SSH does. The banner shows a short form, like 7F3A-91C2-0B5E.

If the key changes later, the game refuses to connect and tells you why. This stops anyone from posing as your server.

The key is in data/cert.der and data/key.der. Back up the data folder: a lost key looks like a new server to every player. Never share key.der.

09 Backups and updates

The world is data/world.toml. The server saves it every 30 seconds and when it stops. It keeps the last 3 copies beside it, world.toml.1 to world.toml.3.

To back up, copy the whole data folder. It holds the world and the key.

To update, run the install command again, then restart the server. With --service, the script restarts it for you.

With Docker:

docker pull ghcr.io/saravenpi/abstractions-server
docker rm -f abstractions

Then run the same docker run line as before. With Compose:

docker compose pull && docker compose up -d

Players need the same game version as the server. An outdated server shows as "Needs vX" in their list.

10 Check it

From another machine, outside your network if you can:

abstractions-server ping your.domain

It exits with 0 when the server answers. Use your public IP if you have no domain.
